# Plurnk

**Put the model in charge of its context, tools, and workflow.**

Plurnk is an open-source agentic operating environment for local and cloud
models. A composable operation language lets agents search with globs, regex,
full text, and structured patterns; curate their own context; and delegate work
to other agents.

- **[Use Plurnk](https://github.com/plurnk/plurnk)** — the terminal client and getting started.
- **[Explore the engine](https://github.com/plurnk/plurnk-service)** — the runtime, language, protocols, and extensions.
- **[Evaluate it](https://github.com/plurnk/plurnk-bench)** — reproducible benchmarks, comparisons, and evidence.

MIT licensed. Bring your own model; no Plurnk account required.
